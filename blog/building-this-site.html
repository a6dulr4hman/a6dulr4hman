Building this site by hand

This site started as a site-builder export, which looked right but was hard to edit. I rebuilt it by hand as plain HTML, CSS and a little JavaScript, so adding a section is just copying a block of markup.

What changed

  • No build step and no framework: open index.html and edit it
  • Design tokens live in one place at the top of the stylesheet
  • Everything is served from local files, with no third-party requests
